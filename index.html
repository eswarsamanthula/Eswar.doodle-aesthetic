01

THFSA — Transformer-Based Hardware Fingerprint Identification

Research prototype for secure scanner authentication. Fingerprint images are evaluated by CNN, Transformer and hybrid models; a Flask demo combines password, TOTP, user-template matching, scanner verification and HMAC session-key agreement.

Tech: Python · PyTorch · TIMM · EfficientFormer-L1 · Computer Vision · Flask · SQLite · bcrypt · TOTP · HMAC-SHA256

Problem, approach & features

Problem: identify the scanner that captured an image. Features: 14 registered architectures; scanner identification and binary verification; MFA flow. Limitation: stored images were used; no physical R307 scanner was connected or tested.

02

Adaptive Traffic Signal Controller

An IoT-based simulation that analyses vehicle demand and calculates adaptive signal timing. MQTT feeds Python decision logic; a simulated actuator acknowledges commands; Node-RED and SQLite support the control-room dashboard and history.

Tech: Python · MQTT · Mosquitto · Node-RED · SQLite · JavaScript · Machine Learning · IoT

Problem, approach & features

Problem: fixed timing does not respond to changing demand. Features: traffic replay, congestion analysis, bounded green times, actuator acknowledgements, Testing Lab and fixed-time comparison. Limitation: software simulation only; no real traffic lights are controlled.

GitHub ↗
03

PRNU Smartphone Authentication

Research implementation inspired by the ABC smartphone authentication protocol. QR challenges lead to phone image capture, PRNU extraction and enrolled-device matching.

Tech: Python · OpenCV · NumPy · Flask · QR Codes · Digital Image Forensics

Problem, approach & features

Problem: check whether a photo came from an enrolled phone camera. Features: PRNU training, challenge-response, mobile upload, forgery/removal checks, PCE evaluation and ROC/statistical visualisations.

Problem: help travellers publish, find and coordinate rides. Features listed reflect implemented screens and API routes in the repository.
