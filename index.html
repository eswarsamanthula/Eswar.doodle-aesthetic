02

SecurePortal

10+ attack scenarios. Custom SQLi, XSS & brute-force modules. A SOC dashboard that actually works.

▼ Read case study

Problem: University security courses teach theory but rarely let students interact with live attack simulations. SecurePortal bridges that gap with a safe, sandboxed environment.

Approach: Built custom SQL injection and XSS payload modules in Flask, with a SOC-style dashboard for monitoring simulated attacks in real time.

Hard bug: The brute-force simulator would lock the test account permanently. Root cause was a missing re-initialization step after each attack reset — fixed by adding a DB seed callback on session teardown.

Outcome: 10+ attack scenarios running. Used by peers for hands-on security practice. Open-source on GitHub.

Tech: Flask · SQLite · Python · Security
